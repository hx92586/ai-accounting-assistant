## 设计上的取舍

- 为保持练习项目可读性，API、数据模型和业务函数目前集中在 `main.py`；后续可以拆分 router、service 和 repository。
- AI 工具复用业务函数，并绑定服务端解析的用户身份。模型负责意图识别与工具参数生成，数据库操作由应用控制。
- 使用进程内 checkpointer 降低本地演示复杂度；多实例部署或持久会话需要外部存储。
- 当前统计按日期区间计算；分类和收支类型筛选作用于账单列表。
- README 中的对话语句是可尝试的输入示例，不是本次执行的模型输出记录。
